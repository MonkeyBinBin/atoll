# 40: 面板輸出搜尋

**What to build:** 在面板的終端機輸出裡用 `⌘F` 搜尋並高亮符合的文字。面板只顯示畫面最後 200 行，想找「剛剛哪個測試失敗」「那個錯誤訊息」目前只能用眼睛捲。只搜尋已經讀進來的輸出，不額外讀取。

**Blocked by:** —

**Status:** ready-for-agent

- [ ] `⌘F`（面板模式）在輸出區上方打開一列搜尋框並聚焦；由 `IslandController` 的 key monitor 攔下（同 `⌘⇧1`–`5`、`⌥↩` 的做法），不讓它落到回覆輸入框
- [ ] 不分大小寫的子字串比對；所有符合處高亮，目前這一個用較強的顏色並捲到可見；搜尋框旁顯示「3 / 12」，沒有結果顯示「No matches」
- [ ] `↩` 下一個、`⇧↩` 上一個（到底循環）；`Esc` 先關搜尋列並把焦點還給回覆輸入框，再按一次才照舊返回清單（`model.escape()` 的優先順序要調整）
- [ ] 搜尋的是畫面上顯示的文字：「Messages only」打開時搜尋過濾後的內容，切換時重新比對；輸出自動刷新時保留關鍵字並重新比對，目前位置盡量停在同一行附近
- [ ] 切到變更檢視（ticket 32）時搜尋列隱藏；換 agent 或關閉面板時清掉關鍵字（只在記憶體）
- [ ] `TerminalOutputView` 是 `NSTextView`：高亮用 temporary attributes 或 text storage 的背景色，不改動文字本身；比對規則（找出所有範圍、上一個／下一個、刷新後重新定位）放成可測的純函式，單元測試：大小寫、多個符合、循環、沒有結果、文字變長後重新定位、空關鍵字
- [ ] 實機確認：長輸出捲動到符合處、Messages only 切換、自動刷新時不跳回頂端

**Out of scope:** 正規表示式、搜尋更早的歷史（超出已讀進來的部分）、跨 agent 搜尋、在 diff 檢視裡搜尋。
