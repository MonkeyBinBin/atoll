# 38: 今日時間軸

**What to build:** 一個「Today」視圖，把每個 agent 今天每個回合結束的時間、狀態、最後一句話與變更量排成時間線。離開一陣子回來，不用逐一打開面板就能知道誰做了什麼、哪些還沒看。資料都已經有：回合結束的判斷（ticket 24 的 `turnEnded`）、最後一句話（`Agent.lastWords`，ticket 35）、變更量（`ChangeSummary`，ticket 28），只差收集與呈現。

**Status:** ready-for-agent

**隱私決策（已確認採用提案）：** ticket 35 規定最後一句話「下一個回合開始就丟棄」，時間線要保留它就得放寬。提案：時間線只存在記憶體，Atoll 結束、日期換日或按「Clear」就丟棄，不寫入磁碟、不放進通知；每筆的文字沿用 ticket 35 的截斷（最多 2 行、每行 200 字）；Settings 可關閉時間線（關閉時不收集）。spec 第 65 條與 README 隱私段落需一併更新。

- [ ] 收集：每次 live transition 判定回合結束（Done／Idle from Working／Exited，以及 Error）記一筆：時間、agent 顯示名稱與工具、專案名、結束狀態、`lastWords`（回合結束當下沒有的話，等 ticket 35 的畫面讀取回來後補上同一筆，不另起一筆）、`ChangeSummary` 的文字（git 算完後補上）。Needs you 不記（它不是回合結束）
- [ ] 上限：只保留今天（本機時間 00:00 起）的紀錄，最多 200 筆，超過丟最舊的；換日時清空
- [ ] agent 被移除或退出後，它的紀錄保留在時間線上（標示已不在），點了不打開面板
- [ ] 顯示：選單列加「Today…」與清單底列加一個入口，打開一個視窗（或動態島的新模式，實作時擇一並說明理由）：依時間倒序，每筆一列「14:32 · Claude Code · atoll · Done · +120 −30 · 最後一句話」；可依 agent 篩選；點了打開該 agent 的面板
- [ ] 「未看」標記：回合結束後使用者還沒打開過該 agent 面板的紀錄加一個點，打開面板後清掉（只在記憶體）；視窗標題顯示未看數
- [ ] 規則（收集、補欄位、上限、換日、未看）放在 AtollCore，fake client 測試：回合結束記一筆、最後一句話晚到補在同一筆、變更量晚到補上、Needs you 不記、上限與換日、移除後保留、打開面板清除未看、關閉時不收集

**Out of scope:** 寫入磁碟或跨 Atoll 重啟保留、匯出、跨天瀏覽、統計圖表、用模型摘要一天的工作。
