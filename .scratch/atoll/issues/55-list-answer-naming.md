## Agent Brief

**Category:** enhancement
**Summary:** 「從清單／面板直接回答」的型別改名、答案到按鍵的對應收成一處、對話框資料以單一型別傳遞；純重構，行為不變

**Current behavior:**
Permission 的 Allow／Deny 與提問選項共用同一條回答路徑，但型別名稱仍是 permission 專用：`PermissionChoice`（含 `case option(QuestionChoices.Option)`）、`PermissionResponseState`、`AgentStore.permissionResponses`、UI 的 `PermissionResponseLabel`。「答案 → 按鍵」的 switch 分散在三處：`PermissionChoice.label`、`PermissionChoices.key(for:)`（為了不可能出現的 `.option` 改成回傳 `String?`）、`AgentStore` 裡只讀 agent 資料的 static `key(for:of:)`。每個 Needs-you episode 讀畫面得到的 preview、permission 選項、提問選項，以三個欄位在 `WaitingPreviewTracker.Result`（`preview`、`choices`、`questionChoices`）→ `AgentStore` 重建 → `Agent`（`waitingPreview`、`permissionChoices`、`questionChoices`）之間逐欄複製。`QuestionButtons` 與 `PermissionButtons` 的外框（讀回覆狀態、送出中停用、尾端狀態標籤）重複，`QuestionButtons` 借用 `AgentPanelView.chipTitle`。提問標題的判斷字元 `"☐☒✔"` 在 `WaitingPreview.claudeQuestion` 與 `QuestionChoices.extract` 各寫一份。

**Desired behavior:**
所有使用者可見行為與現在完全相同（按鈕、快捷鍵 ⌘Y／⌘N、通知動作、送出狀態文字如「Allow sent」「飯 sent」「No longer waiting」、episode 檢查、auto-advance）。程式結構改為：
- 回答的型別名稱涵蓋兩種答案（例如 `ListAnswer`，名稱可自選但要能涵蓋 Allow／Deny 與提問選項），回覆狀態、store 的字典、UI 標籤跟著改名。
- 「某個答案對這個 agent 該送哪個按鍵、目前是否還提供」只有一個入口，放在 agent 這一側（例如 `Agent` 上的方法）；`PermissionChoices` 只處理 Allow／Deny，按鍵查詢回到非 optional。
- 一個代表「本 episode 從畫面讀到的對話框」的型別，包含 preview、permission 選項、提問選項；tracker 產出它，store 重建時整個交給 `Agent`，不再逐欄複製。注意：有 `statusMessage` 時 preview 仍以 msg 為準（現行 tracker 的 `keepPreview` 規則），這個規則要保留。
- 兩種按鈕列共用一個外框元件；chip 標題截短的 helper 放在兩者都能用的中立位置。
- 提問標題判斷字元抽成一個具名常數，`WaitingPreview` 與 `QuestionChoices` 共用。

**Key interfaces:**
- `PermissionChoice` → 新名稱；`PermissionResponseState` → 新名稱；`AgentStore.permissionResponses` 與 `AgentStore.respond(_:to:episode:completion:)` 的參數型別跟著改
- `PermissionChoices.key(for:)`：從 `String?` 改回只接受 Allow／Deny、回傳 `String`
- `WaitingPreviewTracker.Result`：改成（或內含）新的對話框型別
- `Agent.waitingPreview`／`permissionChoices`／`questionChoices`：可改為一個屬性，或保留為由該型別衍生的計算屬性（呼叫端很多，擇一即可，但資料來源只能有一份）
- 呼叫端包含 `Notifier`（通知的 Allow／Deny 動作）、`IslandModel.respondToSelected`、`DebugHook` 的 allow／deny 指令、清單列、hover card、面板
